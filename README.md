# 📱 Flutter Portfolio App

A modern and responsive portfolio application built with Flutter to showcase personal information, skills, projects, education, experience, and contact details.

## ✨ Features

* 🏠 Home Screen
* 👤 About Me
* 💻 Skills Section
* 📂 Projects Showcase
* 🎓 Education
* 📞 Contact Information
* 📱 Clean & Responsive UI

This project focuses on Flutter UI design, responsive layouts, smooth navigation, and creating a professional portfolio application using Flutter.
